# LA CRÈME — Premium Digital Pâtisserie

> **Contemporary French Pâtisserie & Luxury Digital Experience**  
> Официальный цифровой бутик кондитерской **La Crème** (Астана, Казахстан).  
> 10 лет гастрономического совершенства LC Family Group (2016–2026), основанный шеф-кондитером **Даной Канапиной**.

---

## 🌟 Ключевые возможности системы

1. **Luxury Editorial дизайн & Арт-дирекция**
   - Индивидуальная концепция Haute Pâtisserie Française: благородная палитра (сливочные, шоколадные и королевские фиолетовые оттенки), display-типографика Cormorant Garamond и Playfair Display.
   - Подлинные фотографии изделий и архивные материалы, извлеченные напрямую из оригинальных бренд-каталогов и меню кондитерской (десерт Porsche, фисташковый рулет, круассаны, эклеры, национальная коллекция Асық и трюфели Дара).
   - Микровзаимодействия и анимации в соответствии с принципами Emil Kowalski и Apple Design (мгновенный отклик при нажатии, тактильные переходы, мягкое раскрытие корзины, поддержка `prefers-reduced-motion`).

2. **Каталог и фильтрация десертов**
   - 11 аутентичных категорий: *Торты на заказ, Мини-торты, Порционные десерты, Французские эклеры, Круассаны, Слойки и выпечка, Испанские чизкейки, Подарочные наборы, Национальная коллекция, Линейка Je Vie (Vegan), Кофе и барные напитки*.
   - Фильтрация по категориям, быстрый поиск, сортировка по ценам, теги *Gluten Free*, *Новинки* и *Предзаказ 24ч*.
   - Выделенные страницы каждого изделия с описанием рецептуры, составом, граммовкой и выбором количества.

3. **Интерактивная корзина и оформление заявки**
   - Корзина в виде скользящей шторки (drawer) с сохранением состояния в `localStorage`.
   - **Серверная верификация цен:** клиентские цены не являются доверенными — итоговая сумма полностью перепроверяется на сервере по базе данных для защиты от подмены данных.
   - Защита от дублирования заявок через серверную идемпотентность (`idempotency_key`).

4. **Выбор даты и временного интервала (Бизнес-логика)**
   - Календарь с блокировкой прошедших дат.
   - Защита предзаказов: для заказных тортов система автоматически блокирует текущий день и требует минимум 24 часа на изготовление.
   - Интервалы времени (10:00–12:00, 12:00–14:00, 14:00–16:00, 16:00–18:00, 18:00–20:00, 20:00–21:30) с проверкой вместимости слота на сервере.
   - Разделение сценариев: бесплатный самовывоз из бутика (Talan Towers) или доставка курьером по Астане.

5. **Telegram-уведомления**
   - Каждая новая заявка мгновенно форматируется в структурированное сообщение для персонала кондитерской.
   - Интерактивные кнопки: *Открыть в админке*, *Позвонить клиенту*, *Написать в WhatsApp*.
   - **Отказоустойчивость:** при недоступности Telegram API заявка надежно сохраняется в базе данных, ошибка журналируется в `notification_logs`, и доступен механизм повторной отправки (`retry`).

6. **Закрытая административная панель**
   - Безопасный вход по HTTP-only подписанным сессиям (`/admin/login`).
   - **Dashboard:** метрики в реальном времени (новые заявки, заказы на сегодня, обороты, статус интеграции Telegram).
   - **Управление заявками (`/admin/orders`):** фильтрация по статусам (*Новая, Ожидает, Подтверждена, В работе, Готова к выдаче, Выполнена, Отменена*), поиск по номеру/телефону, история изменений, ведение внутренних заметок для персонала.
   - **Управление каталогом (`/admin/products`):** изменение цен, названий, составов, веса, скрытие/возврат товаров в каталог, создание новых изделий.
   - **Настройки расписания (`/admin/settings`):** управление рабочими часами, лимитами заказов на каждый интервал, тестирование Telegram-бота.

## 🛠 Технологический стек

- **Frontend & Fullstack Framework:** Next.js 15 (App Router, Server Components & Server Actions)
- **Язык разработки:** TypeScript 5
- **Стилизация & UI:** Tailwind CSS, Lucide Icons, Google Fonts (Cormorant Garamond, Playfair Display, Plus Jakarta Sans)
- **База данных:** SQLite (через высокоскоростной `better-sqlite3` с режимом WAL и транзакциями)
- **Тестирование:** Автоматизированный интеграционный тест-сьют (`scripts/test_flow.mjs`)

## 🚀 Быстрый старт и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Инициализация базы данных и каталога
```bash
node scripts/seed.mjs
```
*Скрипт автоматически создаст базу `data/lacreme.db`, 11 категорий, 69 аутентичных десертов с реальными ценами и учетную запись администратора.*

### 3. Настройка переменных окружения
Скопируйте пример конфигурации:
```bash
cp .env.example .env.local
```
Отредактируйте `.env.local` при подключении Telegram-бота:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
ADMIN_SESSION_SECRET=your_super_secret_key_here
NEXT_PUBLIC_APP_URL=http://localhost:3000
```
*(Если Telegram-токены не указаны, сайт продолжает полноценно работать, сохраняя заявки в базе и фиксируя статус ожидания уведомлений).*

### 4. Запуск сервера разработки
```bash
npm run dev
```
Сайт будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

### 5. Production сборка
```bash
npm run build
npm run start
```
